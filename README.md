# ExpoMatch – Call aperte per esporre in Romagna

Pagina "link in bio" di @expomatch: le call per espositori aperte in Romagna, in ordine di scadenza.
Ogni evento porta direttamente al modulo di candidatura dell'organizzatore.

- Gli eventi sono nella lista `EVENTI` dentro `index.html`.
- Un evento sparisce da solo dopo la data `fine`.
- Visite e tocchi su "Candidati" vengono contati con GoatCounter (senza cookie).
